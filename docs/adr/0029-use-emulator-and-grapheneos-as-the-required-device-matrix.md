# Use emulator and GrapheneOS as the required device matrix

Compatibility gates require the API 35 AOSP emulator and the current GrapheneOS reference Pixel. Stock Android Pixel and low-memory phone runs are optional observations, not phase or release blockers. This pair covers the minimum supported Android API and the project's primary physical target without making unavailable hardware a permanent delivery dependency. Phase 0 closes with the recorded emulator and GrapheneOS Pixel 10a evidence.
