# Support portable backups without telemetry

Quicklauncher supports versioned Storage Access Framework export and import archives plus Android's transport-independent backup hooks. Users choose the archive folder, and the backup library scans compatible files already present there. Manual and automatic backups appear on separate pages; nightly backups run while charging, retain seven snapshots, and never prune manual archives. Users may protect an archive with a passphrase or explicitly choose plaintext. Import first previews the archive and backs up current state, then atomically replaces the destination map; themes and web adapters may be imported separately. Permissions and document grants require reauthorization, and widgets require new bindings. Nothing leaves the device automatically; diagnostics remain in a bounded local log until the user exports a redacted support bundle.
