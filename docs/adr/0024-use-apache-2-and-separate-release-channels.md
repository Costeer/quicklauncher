# Use Apache 2.0 and separate release channels

Quicklauncher is published under Apache License 2.0. Stable and preview builds use separate application IDs, GitHub release channels, signing identities, and Obtainium configurations, with one APK in each release. Compatibility and performance gates use the reference devices defined by [ADR 0029](0029-use-emulator-and-grapheneos-as-the-required-device-matrix.md).
