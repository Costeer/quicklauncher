# Own the Material theme and import boundaries

The host generates Material You and Material Expressive palettes through Material Color Utilities and stores named launcher-wide theme profiles with bounded module overrides. Image-derived themes retain the seed, palette, and small preview rather than the source image unless the user embeds that image as the theme background. Applying an embedded wallpaper previews its crop, asks whether to target home, lock, or both, and warns that the displaced static or live wallpaper may not be recoverable. Users may import validated static font families or variable fonts, a documented Nova and ADW icon-pack subset, and declarative HTTPS web-search adapters. Imported fonts are copied into private storage, icon mappings fall back safely, and web adapters cannot execute code.
