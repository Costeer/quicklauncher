# Onboard with templates and contextual permissions

First run offers modular sample, traditional, and blank templates; the modular sample places a grid start destination at the center, search above it, and alphabetical apps to the right. Users may preview and configure the result before Quicklauncher requests the Home role. Contacts, files, notifications, wallpaper, and other access are requested only when the user enables or invokes the related feature. Launcher Settings remains host-owned transient UI rather than a destination, so recovery never depends on map state.
