# Make accessibility and quality part of module registration

Registry inclusion requires TalkBack semantics, logical focus order, scalable text, contrast checks, reduced motion, keyboard or D-pad operation, and non-drag editing actions. Each module also supplies metadata, schema migration tests, state-action contract tests, preview fixtures, accessibility tests, and screenshot tests. Release gates include macrobenchmarks for Home entry, spatial gestures, app-catalog loading, search, and the current-plus-neighbors memory model.
