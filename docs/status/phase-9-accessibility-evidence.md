Status legend:

- **LP** — repository-native local executable evidence exists. The cited assertion or visual accessibility check covers only the named behavior.
- **DR** — requires execution on the compatible authorized Android emulator/device or platform/provider integration. A checked-in instrumented test is cited where one exists; an SDK-suppressed test is not upgraded by an otherwise passing device matrix.
- **NA** — not applicable for the stated reason.
- **GAP** — no executable evidence found for the requirement after targeted searches of `app`, `host`, `modules`, and `contracts` main/test/androidTest sources and checked-in snapshots.
