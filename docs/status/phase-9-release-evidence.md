## Design-smell decisions

- `RestoreAuxiliaryPort` was deepened because the overload surface directly obscured restore validation/staging context and release-safety tests. It now accepts immutable validation and staging request types.
- `ProductionSelectedLayoutShell` was extracted from the broad composition root because it creates an exact production visual and focus/key seam while preserving the same navigation state and module boundary.
- `MainActivity` remains the Android composition root. Splitting it now would create shallow pass-through types; revisit when a second host/lifecycle workflow can own a coherent policy boundary.
- `AndroidThemeAssetStore` retains its broad security-critical file validation/locality responsibility. Revisit when a second storage adapter exists or its persistence and validation policies evolve independently.
- Stable and preview release workflows intentionally duplicate their protected channel steps. A shared implementation is deferred until it can retain channel-specific environment, application-ID, and certificate reviewability without introducing indirection.
