# Quicklauncher

Quicklauncher is an Android 15+ home app built around a two-dimensional destination map and build-time contribution modules. The project is not distributed through Google Play and has no in-app updater.

- [Install, upgrade, back up, restore, and recover](docs/user-guide.md)
- [Verify a release APK](docs/release-verification.md)
- [Architecture and implementation status](docs/architecture/launcher-architecture-plan.md)
- [Apache 2.0 license](LICENSE)

No public APK should be treated as a Quicklauncher release until its GitHub draft has passed the documented application-ID, tag, certificate, provenance, and digest verification.
